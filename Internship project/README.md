# Customer Churn Prediction Project

This project predicts customer churn using standard machine learning classification algorithms based on behavioral and demographic indicators.

## Project Structure
* `data.csv`: Source dataset containing historical customer records.
* `eda.py`: Script for basic data inspection and exploring churn patterns.
* `train.py`: Script handling feature engineering, model training, and performance metrics calculation.
